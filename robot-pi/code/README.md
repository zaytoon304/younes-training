# برامج نبيه 🤖

برامج دورة «روبوتي الذكي» على منصة جذور، للروبوت «نبيه» على Raspberry Pi 4.

## التثبيت (مرة واحدة، يعملها المعلم)
افتح الطرفية في الـ Pi، والصق هذا الأمر:

```bash
curl -sL https://zaytoon304.github.io/younes-training/robot-pi/code/install.sh | bash
```

يضع كل البرامج في المجلد `~/nabeeh`. افتحها من Thonny، واحفظ برامج الطلاب الجديدة في نفس المجلد.

## الملفات
| الملف | الوحدة | ماذا يفعل |
|---|---|---|
| `nabeeh.py` | — | مكتبة نبيه: كل الأوامر البسيطة التي يستعملها الطلاب |
| `04_blink.py` · `04_button.py` | ٤ | الليد يومض، والزر يشغّله |
| `05_motor_test.py` · `05_dance.py` | ٥ | اختبار العجلتين، ورقصة نبيه |
| `06_distance.py` · `06_avoid.py` | ٦ | قياس المسافة، والتجول دون اصطدام |
| `07_find_ball.py` · `07_follow_ball.py` | ٧ | البحث عن الكرة الحمراء ولحاقها |
| `08_add_friend.py` · `08_greet.py` | ٨ | حفظ وجه صديق، والسلام عليه باسمه |
| `09_say.py` · `09_chat.py` | ٩ | الكلام، والحوار بالصوت |
| `10_brain.py` | ١٠ | الأوضاع الثلاثة: مستكشف، وحارس، وغميضة |
| `11_remote.py` | ١١ | التحكم من الجوال: `http://nabeeh.local:5000` |

## التوصيل (أرقام GPIO)
| القطعة | GPIO | رقم الدبوس |
|---|---|---|
| الليد / الزر | 17 / 27 | 11 / 13 |
| L298N: IN1 · IN2 · IN3 · IN4 | 5 · 6 · 20 · 21 | 29 · 31 · 38 · 40 |
| الألتراسونك: TRIG / ECHO (عبر مقسّم جهد) | 23 / 24 | 16 / 18 |

## العقل السحابي (اختياري، للوحدة التاسعة)
ضع مفتاح Gemini في الملف `~/nabeeh/gemini_key.txt`. بدونه يعمل كل شيء ما عدا `ask()`.

> صور الوجوه وبصماتها تبقى على الـ Pi فقط، ولا تُرفع لأي مكان. احذفها بـ `nabeeh.forget_friend("الاسم")`.
