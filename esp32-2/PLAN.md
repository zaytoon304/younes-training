# خطة «ESP32 للمعلمين — الجزء الثاني: يحسّ… يتحرك… ويتصل بالعالم»

> منصة جذور · أ. محمد زيتون · بُنيت 2026-10-03 · طلب المدرّب: «أقوى بكثير من الجزء الأول ومن الأردوينو ٢… ابتكر وخليك مفصّل لأن دي غير الأردوينو خالص»

## الفكرة
كل مشروع من «الأردوينو ٢» يُبنى على ESP32 (٣٫٣ فولت، ١٢ بت، LEDC، مقسم جهد) ثم يُضاف له البُعد الرابع **«يتصل»**: جوال، شبكة، لوحة أخرى.
نموذج الطبقات الأربع في كل مشروع: يحسّ ← يقرر ← يتحرك ← يتصل.

## ما يجعلها أقوى
1. **٢٠ شريحة «شرح وافٍ»** (نوع explain من الجزء الأول، مع ١٧ مشهدًا جديدًا في widgetsF3.js): map، مقسم الجهد، المكتبة، المرحّل، pulseIn، مقسم Echo، الراوتر، 2.4/5GHz، RSSI، IP، HTTP، URL، JSON، ESP-NOW، MAC، Callback، STA/AP، millis.
2. **١٢ مختبرًا تفاعليًا جديدًا** يتلوّن فيه السطر المنفَّذ:
   - widgetsF.js: fhero، fadc (ESP32/الأونو/«الحقيقة»: عدم الخطية)، fldr، fdht (nan عند فصل السلك + DHT11)، fsonar (Echo بلا مقسم = تحذير ٥ فولت)، fpir (لا يرى الساكن + لحن مسموع)، fservo (عرض النبضة + بوابة)، fmotor (جسر H + تماس S1+S3).
   - widgetsF3.js: fwifi (مسح، 5GHz غير مرئي، كلمة مرور خاطئة، بعد، رسائل DHCP الأربع)، fweb (جوال ← راوتر ← خادم: GET/200/404)، fdash (JSON كل ثانيتين + زر وسيرفو من الجوال)، fnow (بث/MAC، المدى ٢٢٠ م)، fcar (قيادة بالضغط المطوّل + توقف تلقائي بالحساس).
3. **٧ دوائر تركيب خطوة بخطوة** (widgetsF2.js): fknobw، fldrw، fdhtw، fsonarw، fpirw، fgatew، fmotorw.
4. **١٧ كودًا مُترجمًا فعلًا** (arduino-cli، esp32:esp32:esp32، core 3.3.7) في code/.
   - المكتبات: DHT sensor library، Adafruit Unified Sensor، ESP32Servo.
   - ملاحظة: صفحات HTML داخل الكود بـ `R"HTML( … )HTML"`، لأن `)"` داخل JavaScript يُنهي النص الخام العادي.
5. **خريطة أطراف موحدة** طوال الدورة: المقبض 34، LDR 35، DHT 4، PIR 33، Trig 26، Echo 27 (بمقسم)، ليد 23، بازر 13، مرحّل 19، سيرفو 18، ENA 14، IN1 16، IN2 17، ENB 32، IN3 21، IN4 22.
6. **كراسة ٣٥ صفحة** فيها قاموس الشرح الوافي (٣ صفحات) ودليل تشخيص الشبكة.
